## 2026-09-05T18:12Z · 2355287-davecthomas · fix/v0.5-hygiene-and-eval

**Decision:** Candidate notes stay on the post-commit hook and land one commit late; commit-msg capture was rejected.
**Why:** post-commit has the sha for provenance and cannot corrupt the commit; commit-msg runs before the commit exists, so a note written there has no sha and adding files from inside that hook relies on index timing git does not guarantee.
**Alternatives:** commit-msg hook writing and staging the note into the same commit.
**Scope:** scripts/shared-repo-memory/commit-capture.py

## 2026-09-05T18:12Z · 2355287-davecthomas · fix/v0.5-hygiene-and-eval
