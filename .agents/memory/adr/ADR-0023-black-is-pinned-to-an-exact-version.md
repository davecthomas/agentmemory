# ADR-0023: Black is pinned to an exact version

## Context

Black's formatting output changes between releases. With a caret range, poetry update could pull a new black and reformat the tree, turning the next unrelated PR into a formatting diff. This repo has no CI beyond the pre-commit hook, so a silent reformat would land unreviewed.

## Decision

Pin black to an exact version in pyproject.toml. Raise the pin in its own commit so the reformat is reviewable on its own.

## Alternatives

A caret range (^25.1): rejected because a minor release can change output. No pin, rely on the lockfile: rejected because the lockfile is regenerated by poetry update.

## Consequences

New black releases are adopted deliberately, one commit each; the pre-commit hook and CI run black --check against the pinned version.
